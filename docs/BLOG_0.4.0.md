# PULSE 0.4.0: nuove filiali su Raspberry Pi

Pacchetto per Raspberry Pi OS Desktop 64 bit Trixie, con server, avvio TV,
backup e aggiornamenti GitHub dedicati. La predisposizione per le nuove filiali
mostra l'IP sulla TV e permette di creare il primo amministratore senza copiare
un codice. Il primo accesso si chiude automaticamente dopo la configurazione.
Le installazioni già in uso mantengono i propri dati e la normale autenticazione.

Stato: preparazione locale, non ancora pubblicata. Collaudo hardware da completare.
