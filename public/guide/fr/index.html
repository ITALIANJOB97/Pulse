DIETIKON · Votre équipe, vos résultats, votre écran

Bienvenue

Pulse affiche les personnes, les résultats et les tâches du magasin sur grand écran. Préparez les contenus dans l’administration : la TV se met à jour automatiquement après l’enregistrement.

Premier accès

Sur le PC Mint, ouvrez http://127.0.0.1:8080/admin. Après une mise à jour, gardez votre compte existant. L’assistant de configuration est réservé aux nouvelles installations.

Une routine simple

Choisissez le mois, la semaine ou le jour avant de saisir les données. Enregistrez, puis ouvrez l’aperçu TV. Les boutons de langue changent l’administration ; la langue de la TV se choisit dans les paramètres.

Commander la TV

Les pages défilent automatiquement. Les flèches permettent de changer de page ; la barre d’espace suspend ou reprend le défilement. Fermez l’aperçu pour revenir à l’édition.
