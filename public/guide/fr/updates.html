Mises à jour

Installez immédiatement une mise à jour ou conservez l’horaire nocturne configuré.

Télécharger et installer maintenant

  1. Ouvrez administration > Mises à jour et choisissez Vérifier maintenant.
  2. Lisez la version et les notes, puis choisissez Télécharger et installer maintenant et confirmez la version affichée.
  3. Laissez le Mint allumé et connecté. Le service vérifie le téléchargement et la sauvegarde avant d’installer. Contrôlez ensuite la version installée.

Avec le service Mint v4, l’installation démarre aussi en journée, si l’installation automatique est suspendue ou reportée. Le minuteur actif lit normalement la demande sous environ 15 secondes ; téléchargement et sauvegarde prennent du temps supplémentaire. Annuler le téléchargement arrête le transfert, sans interrompre une installation commencée.

Si le bouton est absent

La fonction immédiate exige le service v4. Une mise à jour ordinaire conserve un ancien service root. Pour mettre à jour immédiatement, téléchargez le ZIP du programme, extrayez-le sur le Mint existant, ouvrez un terminal dans le dossier extrait et lancez sudo bash deploy/upgrade-mint.sh --channel blog. Utilisez --channel github pour conserver GitHub. Cela met à jour l’application et le service après sauvegarde vérifiée. Consultez AGGIORNAMENTO_LINUX_MINT.txt. Gardez vos comptes et ne recommencez pas la configuration initiale.

Source et mises à jour automatiques

Les réglages indiquent la source utilisée. Le service blog v1 lit stable.json ; v4 lit update.json. Publier sur le blog ne met pas à jour un PC configuré pour GitHub, qui exige une Release GitHub complète et signée. V4 vérifie toutes les 6 heures ou manuellement avec Vérifier maintenant. Les anciens services conservent leur intervalle.

Sans demande immédiate, l’installation automatique utilise la plage nocturne configurée, généralement 03:00–04:00 Europe/Zurich. Reporter diffère d’au moins 24 heures. Seules les versions facultatives peuvent être ignorées.

Installation et récupération

Pulse vérifie le paquet et la sauvegarde, suspend brièvement l’édition, remplace le code et contrôle le résultat. En cas d’échec, il tente de restaurer la version et les données précédentes. Une source indisponible n’arrête pas l’affichage. N’éteignez pas le PC pendant l’installation. Conservez le rapport diagnostica à côté du paquet ou lancez sudo bash deploy/diagnose-mint.sh. Ne supprimez pas /var/lib/pulse.

Activer le bouton sans réinstaller l’application

Téléchargez et extrayez la version 0.3.2 sur le Mint. Ouvrez un terminal dans le dossier extrait contenant deploy/. Pour un PC utilisant déjà GitHub, exécutez :

sudo python3 deploy/updater.py bootstrap --source "$PWD" --channel github

Une fois la commande terminée sans erreur, rechargez Updates et lancez une vérification. Le bouton Télécharger et installer maintenant devient disponible pour une version plus récente compatible. La commande met à jour le service en conservant l’application et les données. Pour le blog, utilisez --channel blog. Conservez tout message d’erreur du terminal.
