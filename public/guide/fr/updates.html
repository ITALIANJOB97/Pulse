Mises à jour

Le PC Mint doit accéder à GitHub par Internet pour télécharger les versions et rester allumé pendant la plage de nuit.

GitHub · ITALIANJOB97/Pulse

Pulse recherche toutes les 30 minutes les versions stables publiées dans le dépôt GitHub privé ITALIANJOB97/Pulse. Un commit seul ne déclenche pas de mise à jour. Mint nécessite un jeton en lecture seule limité à ce dépôt, configuré une fois avec sudo python3 deploy/configure-github-mint.py depuis le paquet extrait. Le jeton reste dans un fichier accessible uniquement à root. Renouvelez-le avec la même commande en cas d’expiration ou de révocation. Le paquet signé est téléchargé avant le créneau nocturne ; une sauvegarde vérifiée précède l’installation.

Premier passage à GitHub

Téléchargez la pièce jointe pulse-0.2.2.zip de la version GitHub privée et extrayez-la. Dans le dossier extrait, configurez d’abord le jeton en lecture seule avec sudo python3 deploy/configure-github-mint.py, puis lancez sudo bash deploy/upgrade-mint.sh. La base, les comptes et les images sont conservés. N’utilisez pas le script de nouvelle installation et ne recommencez pas la configuration. Détails : AGGIORNAMENTO_LINUX_MINT.txt.

Mises à jour automatiques

Le canal signé est contrôlé toutes les 30 minutes. L’administrateur voit la version, les nouveautés et l’installation prévue. Par défaut : 03:00–04:00, Europe/Zurich. Une plage manquée est reportée. Une source indisponible n’arrête pas l’affichage.

Vos commandes

Vérifier maintenant demande un contrôle normalement traité dans les cinq minutes. Modifiez l’heure ou mettez l’installation en pause dans les paramètres. Reporter attend au moins 24 heures. Réessayer programme une nouvelle tentative dans la prochaine plage autorisée après un échec.

Pendant l’installation

Pulse vérifie le paquet et la sauvegarde, suspend brièvement l’édition, installe et contrôle le résultat. En cas d’échec, l’ancienne version et la base sont restaurées avant de rouvrir l’édition. Après succès la TV se recharge et affiche la notification. N’éteignez pas volontairement le PC pendant l’opération.

En cas de problème

Un rapport texte est créé dans diagnostica à côté du paquet. Copiez-le sur USB pour le support. Vous pouvez aussi lancer sudo bash deploy/diagnose-mint.sh. Si la récupération échoue, gardez les fichiers et transmettez le rapport ; ne supprimez pas /var/lib/pulse et ne relancez pas la configuration.
