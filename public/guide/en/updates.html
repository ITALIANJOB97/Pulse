Updates

Check and install an update immediately, or keep the configured night schedule.

Download and install now

  1. Open administration > Updates and select Check now.
  2. Read the version and release notes, then select Download and install now and confirm the displayed version.
  3. Keep the Mint PC powered on and online. The service verifies the download and safety backup before installing. After success, check the installed version.

With Mint service v4, this installs outside the night window, even if automatic installation is paused or postponed. The active timer normally reads the request within about 15 seconds; download and backup take additional time. Cancel download stops a transfer; it cannot interrupt an installation already started.

If the button is missing

Immediate controls require service v4. An ordinary application update preserves an older root service. For an immediate upgrade, download the program ZIP, extract it on the existing Mint PC, open a terminal in the extracted folder and run sudo bash aggiorna-ora.sh --channel blog. Use --channel github to retain GitHub instead. This updates the application and service with a verified backup. Follow AGGIORNAMENTO_LINUX_MINT.txt. Keep your existing accounts and do not repeat initial setup.

Source and automatic updates

Settings shows the source used by the installed service. Blog service v1 reads stable.json; v4 reads update.json. Uploading to the blog does not update a PC configured for GitHub. A complete signed GitHub Release is required on that channel. V4 checks every 6 hours, or manually with Check now. Older services retain their existing interval.

Without an immediate request, automatic installation uses the configured night window, normally 03:00–04:00 Europe/Zurich. Postpone delays it by at least 24 hours. Skip is available only for optional versions.

During installation and recovery

Pulse verifies the package and backup, briefly pauses editing, switches the code and checks the result. On failure it attempts to restore the previous version and data. An unavailable update source does not stop the display. Do not power off during installation. For support, retain the report in diagnostica next to the extracted package or run sudo bash deploy/diagnose-mint.sh. Do not delete /var/lib/pulse.
