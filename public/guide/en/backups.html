Backups and history

Download a copy to USB periodically; a backup on the same PC does not protect against disk failure.

Daily and weekly

The service keeps 30 daily backups and 12 weekly backups. Snapshots record the display content for the period, including names and the Sunday setting. Open an archive to view the recorded screen.

Manual backup

Open Backups and choose Create backup. Download the resulting ZIP and keep it somewhere safe. It contains the database and referenced images, including administrator data. Manual retention is ten copies.

Before an update

Every update requires a verified safety backup. Five protected pre-update copies are retained separately from ordinary backups. They are downloadable from Backups. The code from the previous version remains on the PC.

Restoration

Do not import a backup over an active dashboard yourself. Stop application writes and follow the restoration procedure in the package or ask the maintainer. The night updater restores code and the pre-update database together if its installation checks fail.
