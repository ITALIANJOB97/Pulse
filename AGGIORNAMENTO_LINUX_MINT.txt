PULSE 0.2.4 — AGGIORNARE SENZA RIPETERE LA CONFIGURAZIONE
======================================================
PER MINT GIÀ CONFIGURATO CON GLI AGGIORNAMENTI NOTTURNI DAL BLOG
Leggere PUBBLICAZIONE_BLOG.txt e caricare PULSE-Blog-0.2.4.zip sul sito come
indicato. Non sono necessari comandi sul Mint. Il collegamento automatico
GitHub pubblico -> Aruba -> Mint è descritto in docs/RELAY_BLOG.txt.
Questo aggiornamento mantiene il servizio blog v1.

PER PASSARE DIRETTAMENTE AL GITHUB PUBBLICO
Questo passaggio è manuale una sola volta perché cambia il servizio root.
1. Se possibile crea un backup manuale dalla Dashboard e scaricalo.
2. Scarica pulse-0.2.4.zip dalla Release GitHub oppure usa il pacchetto
   PULSE-Dietikon-Linux-Mint-0.2.4.zip. Decomprimilo sul Mint.
3. Apri il terminale nella cartella che contiene deploy/ ed esegui:
       sudo bash deploy/upgrade-mint.sh
4. Attendi il messaggio di installazione riuscita. Apri la Dashboard con
   lo stesso account: http://127.0.0.1:8080/admin.
Non serve alcun token GitHub sul Mint. Non eseguire install-mint.sh o un
nuovo setup e non cancellare /var/lib/pulse.

COSA VIENE CONSERVATO
Database, amministratori/password, Mitarbeiter, immagini, contenuti,
impostazioni e archivi. Il servizio crea e verifica un backup prima del
cambio di codice; in caso di errore è previsto il ripristino della versione
precedente e dei dati. I file del negozio restano in /var/lib/pulse.

SERVICE PODIUM
Valori decimali come 0.6, 0.8 e 1.25 ora sono salvati e mostrati correttamente.
Punto e virgola sono accettati come separatori decimali. I valori che una
vecchia versione ha già troncato a interi non possono essere ricostruiti:
reinserire i risultati corretti. Non vengono inventati o ricalcolati.

PROSSIMI RILASCI
Dopo il passaggio al servizio v3, il Mint controlla GitHub circa ogni 30 minuti,
scarica la release firmata e la installa nella finestra notturna dopo backup.
Per impostazione iniziale: 03:00–04:00 Europe/Zurich. Il PC deve restare acceso,
collegato a Internet e con installazione automatica attiva e non rinviata.
Se un controllo fallisce, PULSE continua a funzionare con la versione presente.

IN CASO DI ERRORE
Lo script produce un rapporto in diagnostica accanto al pacchetto estratto.
Si può usare anche sudo bash deploy/diagnose-mint.sh e copiare il rapporto
su USB. Conservare i file esistenti; non cancellare i dati e non ripetere setup.
